# Polonez Kamper

**Budżetowa adaptacja Poloneza Karetki na elektryczny Camper Truck**  
Open-source • Circular DIY • Low-Cost • Upcycling

## Wizja

Wziąć istniejącą (lub odbudowaną) Polonez Karetkę / Cargo z wysokim dachem i przerobić ją na prosty, tani, elektryczny kamper o charakterze „truck + living space”.

Cel: maksymalnie niski koszt wejścia, możliwość samodzielnej budowy, realna użyteczność do weekendów i dłuższych wyjazdów.

## Zasady projektowe

1. Maintainability First
2. Circular DIY + Low-Cost
3. Maksymalny upcycling i reuse (karoseria Karetki + części ze złomu + druk 3D)
4. Prosta zabudowa mieszkalna – bez luksusu, z funkcjonalnością
5. Napęd elektryczny zgodny z linią Polonez Błyskawica (kasety, power pack, DIY)

## Wstępna koncepcja

### Baza
- Polonez Karetka / Cargo (wysoki dach laminatowy) – idealna przestrzeń na start
- Alternatywnie: Truck z nadstawką

### Napęd
- Konwersja EV w duchu Circular DIY (Leaf EM57 lub podobny, kasety baterii, open-source kontroler)
- Cel zasięgu: 150–250 km realnie (wystarczający do kampera budżetowego)

### Zabudowa mieszkalna (minimalna, low-cost)
- Łóżko (stałe lub składane)
- Prosty aneks kuchenny (kuchenka gazowa / indukcja 12/24V, zlewozmywak)
- Szafa / schowki
- Opcjonalnie: toaleta chemiczna lub kompostowa
- Oświetlenie LED, wentylacja, ewentualnie mały boiler / ogrzewanie postojowe
- Panele solarne na dachu (wspomaganie 12V)

### Charakter „Camper Truck”
- Możliwość otwartej przestrzeni ładunkowej lub uniwersalnej zabudowy
- Łatwy dostęp serwisowy do baterii i napędu
- Proste materiały: sklejka, blacha, druk 3D, recykling
